# AI Growth OS: Open-Source Tool & Skill Registry

This registry provides Shothik agents with pre-mapped access to 37 open-source tools and skill interfaces across 10 operational hubs.

## Hub 1: Core AI & Agents
- **LangGraph**: `https://github.com/langchain-ai/langgraph` — Stateful multi-agent orchestration and memory management.
- **CrewAI**: `https://github.com/joaomdmoura/crewAI` — Role-based AI agent collaboration for complex workflows.
- **Dify**: `https://github.com/langgenius/dify` — Open-source LLM app dev platform with RAG and visual workflows.
- **Flowise**: `https://github.com/FlowiseAI/Flowise` — Drag-and-drop UI to build LLM flows and chatbots quickly.

## Hub 2: Web & Browser Tools
- **Crawl4AI**: `https://github.com/unclecode/crawl4ai` — Fast, AI-optimized web crawling and structured data extraction.
- **Firecrawl**: `https://github.com/mendableai/firecrawl` — Turns entire websites into LLM-ready markdown or structured data.
- **Playwright (Python)**: `https://github.com/microsoft/playwright-python` — Cross-browser automation for testing, scraping, and form filling.

## Hub 3: SEO & GEO
- **SerpBear**: `https://github.com/nicgene/serpbear` — Self-hosted, open-source search engine position tracker.
- **OpenSEO**: `https://github.com/every-app/open-seo` — All-in-one SEO suite including audits, rank tracking, and AI content.
- **python-seo-analyzer**: `https://github.com/sethblack/python-seo-analyzer` — Analyzes site structure and warns of technical SEO issues.

## Hub 4: WhatsApp & Social
- **Evolution API**: `https://github.com/evolution-foundation/evolution-api` — Production-ready REST API for WhatsApp multi-channel messaging.
- **Baileys**: `https://github.com/WhiskeySockets/Baileys` — Unofficial, lightweight WhatsApp Web API written in TypeScript.
- **Chatwoot**: `https://github.com/chatwoot/chatwoot` — Open-source customer engagement suite with WhatsApp/FB integration.
- **Typebot**: `https://github.com/baptistearno/typebot.io` — Visual drag-and-drop builder for conversational WhatsApp/Messenger bots.

## Hub 5: E-commerce
- **Medusa.js**: `https://github.com/medusajs/medusa` — Open-source headless commerce engine (Shopify alternative).
- **WooCommerce (REST API)**: `https://github.com/woocommerce/woocommerce` — Core e-commerce engine for WordPress integrations.
- **Shopify Python API**: `https://github.com/Shopify/shopify-python-api` — Official wrapper for Shopify Admin and Storefront APIs.
- **Saleor**: `https://github.com/saleor/saleor` — GraphQL-first, headless e-commerce platform in Python/Django.

## Hub 6: Email & Marketing
- **Listmonk**: `https://github.com/knadh/listmonk` — Self-hosted, high-performance newsletter manager.
- **Mautic**: `https://github.com/mautic/mautic` — Open-source marketing automation for email, social, and lead tracking.
- **Novu**: `https://github.com/novuhq/novu` — Open-source notification infrastructure (email, SMS, push, in-app).

## Hub 7: Media Generation
- **Whisper (OpenAI)**: `https://github.com/openai/whisper` — Multilingual speech recognition and transcription.
- **Piper TTS**: `https://github.com/rhasspy/piper` — Fast, local neural text-to-speech engine.
- **ComfyUI**: `https://github.com/comfyanonymous/ComfyUI` — Node-based GUI for Stable Diffusion workflows.
- **Remotion**: `https://github.com/remotion-dev/remotion` — React-based framework for programmatic video creation.

## Hub 8: South Asian NLP
- **IndicTrans2 (AI4Bharat)**: `https://github.com/AI4Bharat/IndicTrans2` — Machine translation for 22 Indic languages (Bangla, Hindi, etc.).
- **IndicBERT**: `https://github.com/AI4Bharat/IndicBERT` — Multilingual BERT model pre-trained on 11 Indic languages.
- **BNLTK**: `https://github.com/sagorbrur/bnltk` — Bangla Natural Language Processing Toolkit.
- **iNLTK**: `https://github.com/goru001/inltk` — Natural Language Toolkit for Indic languages.

## Hub 9: Data, Automation & Analytics
- **n8n**: `https://github.com/n8n-io/n8n` — Fair-code workflow automation tool with native AI nodes.
- **Activepieces**: `https://github.com/activepieces/activepieces` — Open-source alternative to Zapier for business automation.
- **DuckDB**: `https://github.com/duckdb/duckdb` — Fast in-process SQL OLAP database for local analytics.
- **Apache Superset**: `https://github.com/apache/superset` — Enterprise BI web application.

## Hub 10: Knowledge Base, RAG & CRM
- **AnythingLLM**: `https://github.com/Mintplex-Labs/anything-llm` — Local RAG and document ingestion desktop app.
- **Qdrant**: `https://github.com/qdrant/qdrant` — High-performance vector search engine.
- **Chroma**: `https://github.com/chroma-core/chroma` — AI-native embedding database.
- **Twenty CRM**: `https://github.com/twentyhq/twenty` — Open-source alternative to Salesforce/HubSpot.
