# 📐 Writing Shape Skill

Use this skill when designing overall manuscript architecture, 3-act structures, or book roadmaps inside `/writing-studio` or `/twin`.

## Core Structural Shapes

1. **The 3-Act Structure (The Turn)**:
   - **Act I (The Setup / 25%)**: Status quo, inciting incident, plot point 1 (no turning back).
   - **Act II (The Midpoint / 50%)**: Rising action, trial, major revelation / false victory / false defeat, plot point 2.
   - **Act III (The Climax / 25%)**: Final confrontation, resolution, new status quo.

2. **Now / Next / Later Roadmap**:
   - Classify all manuscript chapters into Now (Active drafting), Next (Outlined & research verified), and Later (Theme notes & future acts).
