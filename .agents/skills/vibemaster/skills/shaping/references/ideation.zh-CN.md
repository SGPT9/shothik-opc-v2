# 发散：真正不同的候选

[English](./ideation.md)（权威版本）

开算子触发时读这份：候选不存在，或桌上的全是同族。证据已经偏向某个方向，或用户只需要确认一个现成候选时，根本不发散。

## 两条路

**快速路**，用户只要几个：切两三个诚实的疆域，私下探索一小池，跨疆域返回要求的数量。不开子 agent，不建文件。

**深度路**，用户明确要很多方向、说别套路、要真探索时：走下面的疆域隔离。

## 生成之前先切疆域

一套候选只用一个划分维度，按意义或机制的来源选：

- 问题按因果位置、受影响方、改变的层级切
- 解法按干预位置切：改输入、改过程、改反馈回路、除来源
- 创意按功能结果、隐喻世界、构词方式，或任务自己暗示的其他意义来源切

语气、受众、格式、大胆程度是修饰,不是疆域。不许为了凑三个标签混用维度。

共同排除项全局写一次。每个疆域再写一行不得进入的相邻地带，指向某个兄弟疆域。用交叉安放检验切法：一个候选不改前提就能放进别的疆域，说明边界是假的，重切。两个诚实的疆域胜过三个假的，空手而归的疆域胜过硬凑的。

每个疆域还要说清它骑在什么张力上：这个任务独有的哪个事实或约束，通过什么机制改变结果。拿掉那个机制后，疆域读起来像放之四海皆准的通用建议，就重划。每个候选都得依赖那个机制，不能只是把主题名换进标题。

被用户否掉的套路是边界，不是锚。把它拿掉后大半候选站不住，说明整套还在绕着它转。重切重生成。

## 深度探索要隔离

深度路上，疆域可分开探索且环境有子 agent 时，一个疆域派一个。每个只拿到共同目标、硬约束、已核实事实、自己的疆域定义和排除项、输出预算。看不到别的疆域的候选，也看不到任何起锚定作用的示例。主 agent 派发前切好疆域，回收后合并，不理会子 agent 的排名。

没有子 agent 就串行跑同样的简报。进每个疆域前重述定义和排除项，不把上一个疆域的候选带进下一个提示。

## 按族去重

比机制、承诺或核心意象，不比表面措辞。同一因果机制换了名词、同一隐喻世界的邻近意象、同一承诺走同一条路送达：算一族。快速检验是把两个候选的对象互换，都还成立就是共享机制，留一个。

留最强的，顺序：硬约束匹配、产生所要改变的能力、易懂程度、区分度。除非用户点名要同族变体，任何一族不得占最终集合的多数。

诚实的族数不够要求的数量时，只给最薄的疆域补一轮，然后如实报告覆盖面。不许用改写凑数。

## 起名

超过三个的命名集合至少覆盖三个语义疆域和三种构词方式（现成词、复合、拼合、隐喻名、造音）。构词多样不等于语义多样。

给紧凑的疆域小标题，每个候选一条短的含义提示，共同注意事项在结尾写一次。名字的可用性（商标、域名）在真正查过之前算未验证。不许凭记忆推断。

## 交付

去重之后，用户要的数量说了算。快速路上：不逐条写风险，不排名，不主动邀请下一轮。用户只要发散时，聚类去重但不排名不逼选。也要收敛时，把幸存者交给关算子（`judging.md`）。

深度路可以带一个更大胆但仍在硬约束内的荒野牌，标明它是边界标记不是名次。用户要新一轮时，避开已经用过的族。

深度发散只在用户想留时才落盘：`.issues/<日期-主题>/ideas.md`，或更清楚的领域名如 `names.md`。
