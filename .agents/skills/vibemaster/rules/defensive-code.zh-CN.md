# 防御性代码只写在真边界

[English](./defensive-code.md)（权威版本）

- 真边界：用户输入、网络/API、文件系统、第三方库、权限、安全、并发、跨进程或跨系统数据。
- 内部模块之间靠类型、schema、显式不变量、fail-fast 和测试，不靠防御性护栏。
- 不许用没有依据的 `?.`、`|| default`、空 catch、吞掉的错误、复制出来的状态、魔法兜底去掩盖上游错误。掩盖内部不变量已破的护栏，是一个比较有礼貌的 bug。
- 每写一个护栏自问：这是在系统边界上，还是在遮一个已经坏掉的内部约定？删了它，哪个测试会红？
