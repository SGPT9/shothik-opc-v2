# Punctuation

In prose, documentation, and commit messages:

- Do not use semicolons (Chinese `；` or English `;`). Use periods (`。` or `.`) instead.
- Do not use dashes as prose punctuation (Chinese `——`, em dash `—`, en dash `–`). Use a comma, a period, a colon, or parentheses instead. Overused dashes are also a well-known tell of machine-written text.

Hyphens (`-`) are untouched: compound words, ranges like `2-3`, CLI flags, and file names all keep them. Semicolons and dashes inside code blocks are legal syntax and must be kept. In table cells, mark "not applicable" with `-` rather than `—`.
