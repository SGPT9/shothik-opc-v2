# 标点

[English](./punctuation.md)（权威版本）

在行文、文档和提交信息中：

- 不用分号（中文 `；` 或英文 `;`）。改用句号（`。` 或 `.`）。
- 不用破折号做行文标点（中文 `——`、em dash `—`、en dash `–`）。改用逗号、句号、冒号或括号。滥用破折号也是机器写作的知名破绽。

连字符（`-`）不受影响：复合词、`2-3` 这类范围、CLI 参数、文件名照用。代码块内的分号和破折号是合法语法，保留。表格单元格里「不适用」用 `-` 标，不用 `—`。
