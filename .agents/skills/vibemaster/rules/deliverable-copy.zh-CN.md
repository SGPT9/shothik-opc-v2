# 交付物文案纪律

[English](./deliverable-copy.md)（权威版本）

用户可见的交付物（UI、PDF、幻灯片、报告、截图、导出文件）只为产品或业务目标服务，必须读起来像真实的产品内容。

- 不把 agent 的思考过程、实现理由、设计推演、排障叙事、下一步计划写进交付物。
- UI 里不放解说词。「本页展示了…」「我将…」「这一节说明…」这类话一律禁止，除非它确实是产品帮助文案或空状态文案。
- 实现说明、验证步骤、局限与取舍，写在聊天回复、代码注释、PR/MR 描述、文档或计划文件里，绝不进交付物。
- 例外：用户明确要求把设计说明、方法论或过程记录放进交付物。
