# Taste Skill: UI Reference Board Prompt

*Copy and paste the following prompt into an Image Generation AI (like Midjourney, DALL-E 3, or Gemini) to generate high-quality, anti-slop UI reference boards before you start coding.*

---

**Prompt:**
> A high-resolution, professional UI/UX reference board for a [INSERT APP TYPE, e.g., FinTech dashboard / E-commerce mobile app]. The design must reject generic, soulless tech templates. Instead, it should exhibit extreme taste: generous whitespace, a strict typographic hierarchy, and a tailored, intentional color palette. Show a multi-screen layout on a clean studio background. The UI elements (buttons, cards, inputs) must look premium, tactile, and highly considered, avoiding basic 1px gray borders. Dribbble style, Behance featured, UI/UX masterpiece, 8k resolution, photorealistic.
