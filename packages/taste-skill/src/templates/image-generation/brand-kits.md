# Taste Skill: Brand Kit Generation Prompt

*Copy and paste the following prompt into an Image Generation AI to generate a cohesive brand kit before building your application.*

---

**Prompt:**
> A comprehensive, premium brand identity kit for a [INSERT BRAND VIBE, e.g., modern sustainable coffee brand / stealth AI startup]. The image should display a perfectly balanced primary and secondary color palette with hex codes visually represented. It must include typography pairing examples showing a distinct heading font and a highly readable body font. Show subtle texture treatments, logo marks, and a set of 4 custom icon styles. The layout should look like a professional brand guidelines poster from a top-tier design agency. Minimalist, expensive, perfectly aligned, 8k resolution.
