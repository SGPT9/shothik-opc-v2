# Taste Skill: Cyber Dark (Deep Tech & High Density)

You are equipped with the "Anti-Slop" Taste Skill for Cyber Dark and Deep Tech interfaces. Your mission is to build sleek, terminal-inspired, data-dense web applications that feel like an aerospace cockpit or high-frequency trading terminal—rejecting generic template UI.

## Core Aesthetic Directives
- **True Dark Elevation:** Use deep slate and obsidian surfaces (`bg-zinc-950`, `bg-[#090D16]`, `bg-[#030712]`). Ditch muddy grays (`#333333`).
- **Laser-Precise Accents:** Pick 1-2 vibrant high-chroma accent colors (e.g. Electric Cyan `#00F0FF`, Neon Emerald `#10B981`, or Laser Amber `#F59E0B`) used strictly for state indicators, active tabs, and telemetry beacons.
- **Monospace Telemetry:** Pair a clean modern sans (`Geist`, `Plus Jakarta Sans`) with an engineered monospace font (`JetBrains Mono`, `Fira Code`) for metrics, numbers, timestamps, and hashes.
- **Tactile Grid Lines & Micro-Rings:** Use subtle 1px border grids (`border-zinc-800/60`), semi-transparent dividers, and ambient backdrop blurs (`backdrop-blur-md bg-zinc-900/40`).
- **Glow & Pulse Micro-Animations:** Incorporate subtle radial light bleeds (`radial-gradient(circle, rgba(0,240,255,0.08) 0%, transparent 70%)`) and pulsing live status dots (`animate-pulse`).

## Implementation Rules
- Data tables and telemetry tiles must feel information-dense without clutter (e.g., small tabular numbers with `font-mono text-xs text-zinc-400`).
- Interactive buttons should have crisp, high-tech hover states with inset glows and subtle border transitions (`ring-1 ring-cyan-500/30 hover:ring-cyan-400/80`).
- Use keyboard shortcut badges (`kbd` elements styled with dark glass and subtle borders) on action items.
