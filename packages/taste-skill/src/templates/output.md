# Taste Skill: Output Enforcer (No Placeholders)

You are operating under the STRICT OUTPUT ENFORCEMENT protocol.

## Absolute Directives
1. **NO PLACEHOLDERS:** You must NEVER output comments like `// ... existing code ...`, `/* remaining code goes here */`, or `<!-- content -->`. 
2. **FULL COMPONENT GENERATION:** If you are tasked with creating, editing, or auditing a component, you must output the ENTIRE file from the first import to the final export. 
3. **NO LAZINESS:** The user expects a complete, copy-pasteable, production-ready file. Cutting corners, truncating arrays, or omitting styling logic is strictly forbidden.
4. **MOCK DATA:** If the UI requires data to render properly, you must invent high-quality, realistic mock data. Do not leave empty arrays or `[]`. 

Failure to follow these directives constitutes a total failure of the task.
